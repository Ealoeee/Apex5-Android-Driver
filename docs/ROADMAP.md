# 版本规划 (Roadmap)

## v0.1.0 (已发布)
- [x] USB Host 接管飞智八爪鱼 5 (`0x37D7:0x2501`) 双通道（XInput + `0xEF` 增强流）
- [x] Shizuku `/dev/uinput` 虚拟原生 Xbox 360 手柄 + `EV_FF` 震动回传
- [x] 背键 `M1–M4` / `LM / RM` 自定义映射 + 陀螺仪辅助右摇杆瞄准

## v0.2.0 (已发布)
- [x] `/dev/uinput` 虚拟 10 指多点触控屏 (`INPUT_PROP_DIRECT` + Protocol B)
- [x] 触屏映射引擎：点击、连发、轮盘摇杆、FPS 无限视角滑动（含陀螺仪叠加）
- [x] 游戏内悬浮窗控制球、半透明键位提示与可视化键位拖动编辑器
- [x] 触屏方案预设与 JSON 持久化 + App 内实时触控校准画板
- [x] GitHub Actions Tag 自动构建并发布 Release APK

## v0.3.0 (已发布)
- [x] **组合键与序列宏支持**：支持修饰键组合触发（如 `LT + X`）与多步延迟序列宏，悬浮窗可视化拖拽各宏步骤坐标
- [x] **方案复制 & 剪贴板 JSON 导入/导出**：支持跨设备分享与备份自定义触屏键位方案
- [x] **0xEF 轮询 URB 队列深化**：将 HID IN 队列深度由 4 扩充至 8，降低调度抖动
- [x] **UI/UX 全面重构**：横屏平板自适应 Navigation Rail + Bento 双列仪表盘 + 16:10 键位蓝图预览 + Edge-to-Edge 深空曜石暗黑主题

## v0.4.0 (当前版本)
- [x] **应用内在线更新 + 持久化签名**：统一本地与 GitHub Actions 签名密钥，支持 GitHub Releases 版本检查、`gh-proxy` 镜像加速、进度条下载及 Shizuku 静默覆盖安装
- [x] **全套飞智空间站 4.0 调校**：左右摇杆独立死区/补偿/响应曲线可视化/圆矩边界/防抖、左右扳机死区/扳机锁/`0x12` 扳机马达波形反馈
- [x] **全键改键 · Turbo 连发 · 手柄连招宏**：标准键+背肩键全自由映射、`3–25 Hz` Turbo 连发、多步非阻塞手柄宏、双马达震动强度缩放、陀螺仪平滑及场景预设 JSON 分享

## v0.5.0 (规划中)
- [ ] **游戏自动识别切换方案**：根据前台包名自动匹配触屏/手柄模式与映射方案
- [ ] **0xEF 轮询回报率深度实验**：分析 Libusb / Native C++ `USBDEVFS_SUBMITURB` 旁路方案以冲击 1000Hz 硬件上限
- [ ] **无线 2.4G 接收器支持调研**：验证 Flydigi 2.4G Dongle VID/PID 与多包协议兼容
